Get demo access

The scdemos demo site (Frescopa) is the shared base for Edge Delivery Services demos. Sign up once and you get:

  • Experience Workspace: write access to the demo site, its block library and apps (group da-demosite-authors in the CAS Hub organization)
  • GitHub: SC-Team in the scdemos organization, so CloneIt can create demo repositories for you
  • Your own demos: each demo you create with CloneIt gets its own repository and folder, and you can edit its content and configuration
